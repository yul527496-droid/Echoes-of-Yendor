# Echoes of Yendor — Chapter 1 art checkpoint (2026-08-16)

This checkpoint preserves the useful art candidates from the 0.0.9 **World & Audio Cohesion RC** pass without wiring them into runtime yet.

## Archives

- `major_npc_art.zip`
  - BigOranger / Master / Serena / Elan / Sindel
  - current pixel-treated splash candidates
  - corrected 48×48 dialogue portraits
  - v4 in-game production sprite sheets
- `surface_art.zip`
  - Farmer De-AI v3 splash, 400×225 pixel master, dialogue portrait
  - Old Crow Innkeeper De-AI v1 splash, 400×225 pixel master, dialogue portrait
  - gray wolf / anomalous bird / donkey / cart / donkey+cart v5 sprite candidates

## Important

This directory intentionally lives under `art/` instead of `core/src/main/assets/` so the checkpoint is preserved in Git without silently changing the packaged game or runtime asset loading.

Rejected blocky portrait experiments and older discarded prototypes are intentionally excluded.
