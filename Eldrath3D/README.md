# ELDRATH 3D

A code-first Godot 4 prototype of **ELDRATH**, built so the playable game can be iterated through GitHub without requiring day-to-day editor work.

## Prototype 0.0.1 — The Nameless Tomb

- third-person movement and orbit camera
- walking, sprinting and jumping
- dark-fantasy tomb greybox built entirely from engine primitives
- no external art assets required
- Windows export preset
- GitHub Actions build produces a downloadable Windows artifact

### Controls

- `WASD` move
- `Shift` sprint
- `Space` jump
- Mouse look
- `Esc` release/capture mouse
