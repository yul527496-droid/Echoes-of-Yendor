# Surface Art v2

Second-pass outdoor scene goals:

- reduce grass noise and visible tile repetition;
- make the old road less grid-like;
- replace the straight canal feeling with a gently irregular stream;
- give the crossing a dedicated timber-bridge floor;
- make forest blockers read more like foliage than green masonry;
- make the dungeon mouth read as an old mossy ruin;
- increase outdoor view distance while retaining exploration fog.

The implementation still uses Shattered Pixel Dungeon's existing 16x16 terrain atlas and Level systems. No separate renderer or world manager is introduced.
