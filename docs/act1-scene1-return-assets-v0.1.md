# Act 1 Scene 1 — Return / 归来 v0.1 candidate asset manifest

Status: runtime/provenance companion to `docs/act1-scene1-return-production-v0.1.md`.

## Runtime visual assets actually used

Scene 1 reuses the accepted project-owned Echoes Chapter 1 surface packs:

- `environment/echoes/ch1_surface/grass.png`
- `environment/echoes/ch1_surface/forest.png`
- `environment/echoes/ch1_surface/road.png`
- `environment/echoes/ch1_surface/river.png`
- `environment/echoes/ch1_surface/bridge.png`
- `environment/echoes/ch1_surface/camp_ruin.png`
- `environment/custom_tiles/echoes_landmarks_v1.png`
- existing native-16px Chapter 1 farmer / donkey-cart / bird / wolf sprite sheets selected by the existing Echoes sprite classes.

Return v0.1 adds one **project-owned deterministic runtime atlas**:

- generator source: `tools/generate_act1_return_props_v1.py`
- runtime path: `environment/echoes/act1_return/return_props_v1.png`
- dimensions: `256×64`, RGBA, native 16px grid
- runtime tilemap: `EchoesReturnPropTilemap`
- validation: generated by `tools/validate_pngs.py`, then checked for PNG signature/chunk CRC/decompression, exact dimensions and 16px alignment.

The atlas supplies four visibly different expedition bedrolls, dead fire, cook pot, travel bag, crate, faded 2×2 tent cloth, checklist/paper, maintenance tools, hanging cloth, milestone, low wall, field edge, sack, farm tool, broken cart wood, shrine offering bowl, subtle four-fold recess, roots and stump. All pixels in this atlas are expressed directly as editable deterministic pixel operations in the generator. No third-party pixel data or embedded binary/base64 payload is present.

## Runtime audio actually used

Return v0.1 intentionally reuses only already-integrated Chapter 1 assets whose build-time fetch/checksum pipeline already exists:

- `music/echoes/ch1_surface_ambience.mp3` — restrained surface forest bed
- `sounds/echoes/ch1_stream_loop.mp3` — proximity stream bed
- `sounds/echoes/ch1_wolves.mp3` — one roadside warning cue
- `sounds/echoes/ch1_yendor_bass.mp3` — short Yendor anomaly signature cue

`ChapterOneAudio.playRaven()` remains intentionally silent because no trustworthy crow source is pinned. `playFarmerApproach()` remains intentionally silent because no verified carriage cue is pinned. Farmer dialogue is text-only Dialogue Stage and **no human/street/tavern voice recording is used by the Return scene**.

No new raw Sonniss sound file is committed for Return v0.1. Sonniss #GameAudioGDC remains an optional future source governed by its official license at `https://sonniss.com/gdc-bundle-license/`: synchronization/modification in games is allowed under the license, but source recordings must not be redistributed as an as-is standalone sound library. The project therefore keeps the existing build-time download → SHA256 verification → packaged-game-asset pattern for any such restricted source.

## Candidate validation

`tools/validate_act1_return_candidate.py` is invoked by `tools/validate_pngs.py`. It fails CI if the locked five-line opening, formal entry, 88×68 map contract, clue information boundaries, shrine inscription, persistent scene state, heard-only Morningcreek handling, safe north transition or required Return dressing regress.
